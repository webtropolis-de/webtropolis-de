## Ausgewähltes Projekt

### Amazon FBA / FBM Rechner

Ein öffentliches Browser-Tool zur schnellen Kalkulation von Amazon FBA- und FBM-Angeboten.

- Live-Demo: https://webtropolis-de.github.io/amazon-fba-fbm-rechner/
- Repository: https://github.com/webtropolis-de/amazon-fba-fbm-rechner
- Tech: HTML, CSS, Vanilla JavaScript, GitHub Pages
- Features: Marge, Deckungsbeitrag, Gebührenaufschlüsselung, PDF-/CSV-/Excel-Export, lokale Speicherung im Browser
